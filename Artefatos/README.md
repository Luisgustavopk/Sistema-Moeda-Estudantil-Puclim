# Artefatos

Este diretório reúne os principais documentos e materiais visuais produzidos para o projeto do Sistema de Moeda Estudantil Puclim.

## Finalidade

Os artefatos armazenados aqui servem para registrar e comunicar a estrutura, a arquitetura e a modelagem da aplicação, facilitando a compreensão do sistema por desenvolvedores, stakeholders e demais interessados.

## Subpastas

- [Modelagem](./Modelagem/README.md): documentos e diagramas que representam a arquitetura e a estrutura do sistema.
