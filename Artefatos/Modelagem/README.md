# Modelagem

Esta pasta reúne os artefatos de modelagem do Sistema de Moeda Estudantil Puclim.

## Objetivo

Os arquivos desta pasta documentam a estrutura conceitual da aplicação, permitindo compreender melhor a organização dos componentes, as entidades envolvidas e as relações entre os elementos do sistema.

## Arquivos disponíveis

- `diagrama_componetes.pdf` — diagrama de componentes da solução, com a representação da interação entre os principais blocos do sistema.
- `diagrama_de_classe.pdf` — diagrama de classes, apresentando as entidades, atributos e relações principais da aplicação.

## Observação

Os arquivos foram organizados para manter uma visão clara da modelagem do sistema e facilitar futuras alterações ou expansões no software.
